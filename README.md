# Facial Recognition Attendance System

## Setup Instructions
1. **Clone the repository**:
   ```bash
   git clone https://github.com/tanuj-asus/tanishk.git
   cd tanishk
   ```  
2. **Install dependencies**:  
   Make sure you have Python 3.x installed and then run:
   ```bash
   pip install -r requirements.txt
   ```  
3. **Set up the environment**:  
   Create a `.env` file in the root of the project and add the necessary environment variables.

## Features
- Real-time facial recognition for attendance
- User-friendly interface
- Supports multiple users
- Generates attendance reports

## Usage Guide
1. **Run the application**:  
   ```bash
   python app.py
   ```
2. Follow the on-screen instructions to register users and mark attendance.

## Troubleshooting
- **If you encounter an error related to missing packages**, ensure all dependencies are installed properly. Check the `requirements.txt` file.
- **For issues with facial recognition**, check your webcam connection and lighting conditions. Ensure your face is clearly visible to the camera.

If further assistance is needed, please consult the project documentation or reach out for support.
